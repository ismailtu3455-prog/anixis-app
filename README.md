# ⚡ Anixis — Онлайн просмотр аниме и совместные комнаты (Watch Together)

Современное Android-приложение для просмотра аниме с поддержкой источников **Animix**, **AniLibria**, **Kodik**, **Kinescope**, манги и функции **совместного просмотра с друзьями в реальном времени**.

---

## 👥 Совместный просмотр (Watch Together / Румы)

В приложении Anixis доступен режим совместного просмотра в реальном времени:
* **Синхронизация воспроизведения:** пауза, перемотка, выбор серий и авто-сглаживание рассинхрона (Heartbeat & микро-ускорение 1.05x).
* **Синхронный чат и живые реакции:** всплывающие эмодзи и текстовые сообщения поверх плеера.
* **Индикация микрофона:** отображение говорящих участников комнаты.
* **Приглашения по ссылке:** создайте комнату и отправьте ссылку другу — при нажатии он сразу попадает в лобби совместного просмотра (nixis://room / /join).

## 🚀 Развертывание личного сервера комнат (1-Click Deploy)

Вы можете развернуть собственный бесплатный WebSocket-сервер комнат на **Cloudflare Workers** в один клик:

[![Deploy to Cloudflare Workers](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/ismailtu3455-prog/anixis-app)

### Как это работает:
1. Нажмите кнопку **Deploy to Cloudflare Workers** выше (или в приложении Anixis: **Профиль** → **Настройки комнат** → **Создать свой сервер**).
2. Войдите в Cloudflare и нажмите **Deploy**.
3. Скопируйте полученный адрес воркера (например: https://anixis-room-server.<username>.workers.dev) и вставьте его в настройки комнат в приложении.
4. *Совет для пользователей из РФ:* привяжите свой собственный домен в настройках Cloudflare Worker или включите VPN для стабильного WebSocket соединения к .workers.dev.
